# BayBlaze Admin

Operator dashboard for BayBlaze accounts, drivers, routes, coverage plots, and
live order details.

```bash
npm install
npm run dev
npm run build
npm run lint
```

Set `VITE_BAYBLAZE_API_URL` to the BayBlaze API origin. Production is expected
to run at `admin.bayblaze.net` against `https://api.bayblaze.net`.
